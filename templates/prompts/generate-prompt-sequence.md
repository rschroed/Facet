# Generate Prompt Sequence

Create a sequence of scoped prompts for external agent execution.

Recommended sequence:

1. Explore three concept directions in Figma.
2. Critique the generated concepts against the brief.
3. Refine the strongest direction.
4. Create a mobile variation.
5. Add annotations.
6. Write rationale and handoff notes.

Each prompt should be independently pasteable and should preserve the boundary that Facets is not the agent runtime.
