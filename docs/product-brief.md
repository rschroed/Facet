# Facets Product Brief

Facets is a lightweight prompt workbench for design ideation. It is for designers who want better results from AI agents and Figma MCP without adopting a heavy product-spec system.

## Core Principle

Facets generates better instructions. External tools execute those instructions.

## Core Artifacts

### Brief

The brief captures the intent of the work:

- project title
- brand or product
- artifact type
- audience
- goal
- required content
- constraints
- tone or editorial direction
- references
- Figma context notes
- things to avoid

### Directions

Directions are concept-level options generated from the brief. Each direction includes:

- title
- summary
- layout or interaction idea
- why it works
- risks or tradeoffs
- suggested Figma execution notes

### Prompts

Prompts are copy-ready instructions for external agent tools. Prompt targets include:

- ChatGPT
- Codex
- Claude Desktop
- Cursor
- generic MCP-enabled tool

Prompts must be explicit that Facets itself has no direct Figma access.

## Early Prototype Success Criteria

The prototype is successful if a designer can create a project, improve a brief, generate useful directions, select one direction, produce a paste-ready prompt, and get better external agent output than they would from an ad hoc prompt.
